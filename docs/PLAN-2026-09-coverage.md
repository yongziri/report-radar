## 5. 데이터 품질·운영
- 투자의견 정규화 표 확장: 와이즈·씽크풀 유입 시 `보유`, `Buy(Maintain)`, `Buy(Reinitiate)`, `매수(신규)`, `N.R`, `Positive`, `[유지] 매수` 등 신규 표기.
- 상세 재시도 상한: 의견이 원래 없는 리포트가 매 실행 재요청되지 않도록 실패 3회 후 포기 플래그.
- `reports.json` 크기: 와이즈 통합 시 180일 누적이 약 12,000건·10MB 이상으로 커짐 → 월별 파일 분할 + 최근 60일만 초기 로드, 나머지는 "전체" 선택 시 지연 로드.
- 소스 상태 패널: meta.json에 소스별 최근 수집일·건수를 기록하고 리포트 탭 상단에 표시(어느 소스가 멈췄는지 화면에서 보이게).
- 종목명은 네이버 시세 정식 명칭으로 통일(적용됨). 와이즈 종목코드와 유니버스 매핑 실패 건은 미분류로 표시.
