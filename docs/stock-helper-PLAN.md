# 주식 대시보드 보완 계획 (핀비즈 대조, 2026-08-03)

핀비즈 실사(홈·스크리너 필터/시그널/뷰·종목 페이지 스탯 그리드) 결과와 현재 앱의 격차 분석.
제약: 단일 HTML, 네이버 JSONP(벌크 시세 + siseJson 이력), rss2json, 500종목 이력 일괄 스캔 금지.

## 1단계 — 추가 데이터 비용 없음 (기존 캐시·스캔 재활용)

1. **관심종목 다기간 성과 컬럼**: 스파크라인용으로 이미 로드하는 30일 이력에서 1주/1개월 수익률 계산해 컬럼 추가. (핀비즈 Perf Week/Month 대응)
2. **업종별 퍼포먼스 패널** (핀비즈 Groups 대응): 스캔 캐시 + 내장 업종 분류로 업종별 등락률(시총가중)·상승종목비율 가로 바 차트. 대시보드 패널 또는 스크리너 내 서브뷰. 업종 클릭 → 해당 업종 필터 적용.
3. **지수 차트**: siseJson symbol=KOSPI/KOSDAQ 동작 실측 확인됨. 헤더 지수 클릭 → 종목분석에서 지수 캔들차트.
4. **스크리너 컬럼 프리셋 뷰 탭** (핀비즈 Overview/Valuation/Performance/Technical 대응): 기존 컬럼 선택기를 묶은 원클릭 프리셋 4종(개요/가치/성과/기술).
5. **공시 유형 필터** (핀비즈 Insider 부분 대응): DART 공시 보고서명 키워드로 지분변동(임원·주요주주 소유상황)/실적/주요사항 분류 탭. 지분변동 = 한국판 내부자거래 신호.

## 2단계 — 호출 비용 있음, 한도 내 (온디맨드 + 캐시 + 진행률)

6. **티커 호버 미니차트 팝업** (핀비즈 시그니처 UX): 대시보드·스크리너 티커 호버 시 미니 캔들 팝업. 이력 캐시 있으면 즉시, 없으면 지연 로드(동시 1건).
7. **스크리너 차트 그리드 뷰** (핀비즈 Charts 뷰 대응): 필터 결과 상위 20개를 미니 캔들차트 그리드로.
8. **심층분석 확장**: 주/월/YTD 성과, 52주 신고/신저 근접(±5%), ATR·변동성 컬럼 + "신고가/신저가" 시그널 프리셋. (기존 50종목 한도 유지)
9. **트리맵 기간 전환** (핀비즈 Maps 1W/1M 대응): 1일 외 1주/1개월 등락 모드 — 150종목 이력 온디맨드 로드(~1분, 진행률 표시, 세션 캐시).

## 3단계 — 신규 소스·구조 변경 (선택)

10. **경제 캘린더**: investing.com 공식 임베드 위젯(sslecal2.investing.com) iframe — 임베드 정책·헤더 실측 후 결정.
11. **멀티 워치리스트/포트폴리오 그룹**: 그룹 전환 탭 (핀비즈 Portfolio 대응).
12. **rss2json 탈피**: 개인 Cloudflare Worker 프록시(무료 100k/일)로 뉴스·공시 안정화 + DART 오픈API(무료 키) 직접 프록시 → 과거 공시 이력까지 확보. 사용자 계정 셋업 필요.

## 불가·보류 (사유 명시)

- **공매도 잔고/Short Float**: KRX 데이터 비개방(CORS·JSONP 없음) → KRX 공매도포털 링크로 대체.
- **미국 스크리너·맵**: Twelve Data 무료로는 벌크 스캔 불가.
- **차트 패턴 자동 인식**(Wedge/H&S 등): 구현 대비 신뢰도 낮음 — 골든크로스·신고가 돌파 등 규칙 기반만 유지.
- **SMA50/200 상회 비율 게이지**: 전 종목 이력 필요 → 호출 제약 위반. 심층분석 50종목 한정으로만.
- **실적 발표 예정 캘린더**: 무료 예정일 소스 없음(DART는 발표 후 공시만).
- **애널리스트 목표가 데이터화**: 원데이터 비개방 — 와이즈리포트 iframe(컨센서스 탭)으로 이미 화면 제공 중.
