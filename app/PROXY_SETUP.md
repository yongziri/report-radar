# 뉴스·공시 프록시 설치 안내 (Cloudflare Worker)

주식 대시보드의 뉴스·공시는 기본적으로 **rss2json** 이라는 무료 공개 서비스를 거쳐 옵니다.
이게 가끔 실패하고(같은 주소를 다시 부르면 되는 식), DART 최근공시도 **50건 중 10건만** 돌려줍니다.

아래 프록시를 한 번만 만들어 두면 그 제한이 사라집니다.

| | 기본(rss2json) | 프록시 설치 후 |
|---|---|---|
| 공시 건수 | 10건 | **50건 전부** |
| 간헐적 실패 | 있음 | 거의 없음 |
| 하루 한도 | 공유 한도 | **10만 요청/일 (개인 전용)** |
| 비용 | 무료 | 무료 (신용카드 등록 불필요) |

소요 시간: **약 5분**. 프로그래밍 지식은 필요 없습니다.

---

## 1단계 — Cloudflare 무료 가입

1. <https://dash.cloudflare.com/sign-up> 접속
2. 이메일 · 비밀번호 입력 후 가입 (신용카드 필요 없음)
3. 메일로 온 인증 링크 클릭

## 2단계 — Worker 만들기

1. 로그인 후 왼쪽 메뉴에서 **Workers & Pages** 클릭
2. **Create application** → **Create Worker** 클릭
3. 이름을 정합니다. 예: `stock-proxy`
   → 주소가 `stock-proxy.<내계정이름>.workers.dev` 로 만들어집니다
4. **Deploy** 클릭 (일단 기본 코드로 배포)

## 3단계 — 코드 붙여넣기

1. 배포된 화면에서 **Edit code** (또는 **</> Edit code**) 클릭
2. 편집기에 있던 기존 내용을 **전부 지우고**,
   이 폴더의 **`cloudflare-worker.js` 파일 내용을 전부 복사해서 붙여넣기**
3. 오른쪽 위 **Deploy** 클릭

## 4단계 — (선택) DART 오픈API 키 넣기

과거 공시까지 보려면 필요합니다. 오늘 공시만 보면 되면 건너뛰세요.

1. <https://opendart.fss.or.kr/> 접속 → **인증키 신청/관리** → **인증키 신청**
2. 이메일 인증하면 40자리 키를 즉시 발급해 줍니다 (무료, 1일 20,000건)
3. Cloudflare 워커 화면으로 돌아가서
   **Settings** → **Variables and Secrets** → **Add variable**
   - Variable name: `DART_KEY`
   - Value: 발급받은 40자리 키
   - **Encrypt** 체크 권장
4. **Deploy** 클릭

> 키를 워커에 넣어두면 앱(index.html)에는 키가 저장되지 않습니다.
> 파일을 남에게 보내도 키가 새지 않습니다.

## 5단계 — 앱에 주소 등록

1. 워커 화면 위쪽의 주소를 복사합니다
   예: `https://stock-proxy.hong.workers.dev`
2. 주식 대시보드에서 **설정** 열기
3. **커스텀 프록시 URL** 칸에 붙여넣고 **저장**
4. 대시보드의 "최근 공시" 패널이 **50건**으로 늘어나면 성공입니다
   (설정 창의 프록시 칸 아래에 현재 동작 모드가 표시됩니다)

---

## 잘 되는지 확인하기

브라우저 주소창에 아래를 붙여넣어 보세요 (`<내워커주소>` 부분만 바꿔서):

```
https://<내워커주소>/?url=https%3A%2F%2Fdart.fss.or.kr%2Fapi%2FtodayRSS.xml
```

XML 이 주르륵 나오면 정상입니다.

## 문제가 생기면

| 증상 | 원인과 해결 |
|---|---|
| `{"error":"허용되지 않은 호스트..."}` | 정상 동작입니다. 이 프록시는 구글뉴스·DART 만 통과시킵니다(아무나 못 쓰게 막아둔 것). |
| `{"error":"url 파라미터가 필요합니다."}` | 주소 끝에 `/?url=...` 을 빠뜨린 경우입니다. |
| 앱에서 여전히 10건만 보임 | 설정에 주소를 저장했는지, 오타(끝의 `/` 는 있어도 됨)가 없는지 확인하세요. |
| 프록시를 껐다 켜고 싶다 | 설정에서 프록시 URL 칸을 **비우면** 기존 rss2json 방식으로 자동 복귀합니다. |

## 보안 메모

- 이 워커는 **구글뉴스 · DART 도메인만** 통과시킵니다. 다른 주소로 요청하면 403 을 돌려줍니다.
  (아무나 쓰는 공개 프록시가 되면 계정 한도가 털리기 때문입니다.)
- 워커 주소는 공개돼도 위 제한 때문에 악용 소지가 적지만, 굳이 남에게 알릴 필요는 없습니다.
- 응답은 5분간 엣지 캐시됩니다. 앱에도 10분 캐시가 있어 실제 요청 수는 매우 적습니다.
